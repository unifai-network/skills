# matrix-workflow：社交媒体自动化内容管理工作流

`matrix-workflow` 是专为 OpenClaw 平台设计的社交媒体运营与自动化分发工作流（Skill）。该技能提供从内容构思、合规性过滤、排版渲染到自动发布的全链路解决方案，主要针对小红书、微信公众号等主流社交平台。

它是 `unifai-network/skills` 生态中的核心调度组件，支持跨技能的协同调用。

---

## 核心特性

- **双模式工作流**：
  - **素材生成模式**：执行文案生成、合规性审查机制（违禁词过滤），并调用底层渲染引擎输出标准的图文卡片集，提供给用户进行发布前的最终审核。
  - **自动分发模式**：在配置有效用户凭据（Cookie/Token）的前提下，调用自动化环境完成过审素材的静默发布。
- **内置合规过滤系统**：针对不同平台的内容风控规则，自动进行敏感词汇和高风险概念（如数字货币、外网等）的重构与洗稿处理，确保内容输出符合本地合规要求。
- **标准化图文渲染引擎**：自动将结构化 Markdown 文本转换为符合小红书等平台原生交互形式的视图卡片，保持视觉输出一致性。
- **模块化调度架构**：支持作为主节点唤醒并协调其他专注单一任务的底层工具（例如数据采集器或自动化发布脚本）。

## 部署与使用指南 (Quick Start)

如果你的设备已成功运行 OpenClaw 环境，无需进行手动的 Git 操作。

请复制以下标准指令，并以提示词形式发送至 OpenClaw 对话框，系统将自动完成该工作流的下载、依赖读取及首次测试：

```text
请安装并启用「matrix-workflow」工作流技能。
技能代码地址：https://github.com/unifai-network/skills/tree/main/matrix-workflow
请将该目录部署提取至本地的 skills 文件夹中。

部署完成后，请读取该目录内的 SKILL.md 配置文件。确认逻辑后，请执行以下首次任务：

【任务指令】：请以“素材生成模式”，围绕 [在此处替换为实际的业务主题] 生成一篇内容，执行标准的合规过滤处理，并输出对应的图文排版结果集。
```

> **注意：**
> 在向 OpenClaw 提交指令前，请将上述指令中括号 `[ ]` 内的变量文本替换为具体的执行需求。

## 关联技术栈与组件参考

本工作流为调度中心枢纽，其底层常与其他离散的专用 Skill 进行组合使用：

- **`xhs-anti-risk-detoxifier`**：文本内容合规审查与重构组件。
- **`xhs-note-creator`**：平台原生视觉风格的图文渲染生成器。
- **`xiaohongshu-publish-skill`**：基于无头浏览器与接口协议的自动化发布执行器。
- **`opentwitter-mcp`**：统一的海外信息源（Twitter/X）标准化抓取网关。
